Einstellungen & Backups

Deine Daten bleiben lokal, bis du Firebase-Cloud-Synchronisierung einrichtest.

Konto & Cloud-Synchronisierung

Melde dich mit derselben E-Mail-Adresse auf deinen Geräten an, damit deine Daten synchronisiert werden. Dafür ist eine einmalige Firebase-Einrichtung auf einer HTTPS-Webseite nötig.

Cloud-Konto wird geprüft …

Firebase einmalig kostenlos einrichten
  1. Erstelle in der Firebase Console ein Projekt im kostenlosen Spark-Tarif und füge eine Web-App hinzu.
  2. Aktiviere unter Authentication die E-Mail/Passwort-Anmeldung und erstelle eine Firestore-Datenbank.
  3. Kopiere die Firebase-Web-App-Konfiguration in firebase-config.js und veröffentliche die Regeln aus firestore.rules.
  4. Installiere Node.js und die kostenlose Firebase CLI mit npm install -g firebase-tools, melde dich mit firebase login an und wähle dein Projekt im PYP-Ordner mit firebase use --add aus.
  5. Veröffentliche mit firebase deploy --only hosting,firestore:rules. Öffne anschließend die HTTPS-Seite auf dem iPhone in Safari oder auf Android in Chrome und füge sie zum Startbildschirm hinzu.

Der Spark-Tarif hat Nutzungsgrenzen. Die Synchronisierung funktioniert erst nach dieser Einrichtung; behalte bis dahin deine Backups.

Daten sichern

Exportiere eine Sicherung als JSON-Datei. Bewahre sie sicher auf. Für einen Gerätewechsel kannst du sie später importieren.

Hinweise

  • PYP funktioniert ohne Konto lokal im Browser. Mit eingerichteter Firebase-Anmeldung kannst du deine Daten zusätzlich geräteübergreifend synchronisieren.
  • Ohne Firebase-Einrichtung werden Daten nicht automatisch zwischen PC und Handy synchronisiert.
  • Ein Backup enthält auch deine persönlichen Einträge. Teile es nur, wenn du das möchtest.
  • Ein importiertes Backup ersetzt die aktuell gespeicherten App-Daten.
